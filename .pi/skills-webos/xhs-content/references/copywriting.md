# 小红书文案方法论（详细版）

> 本文件是 `xhs-content` skill 的文案深度参考。标题速查表在 SKILL.md §二，本文展开完整写作方法、案例拆解与自检清单。

## 0. 写作前：一句话定位

动笔前先写出一句话定位（写不出就回去问用户）：

> **「这篇笔记是写给 [谁]，帮他们解决 [什么问题]，看完后 [获得什么]。」**

整个标题、正文、封面都围绕这句话。定位不清晰 = 写什么都飘。

## 1. 标题：信息流里的 0.5 秒

### 1.1 硬指标
- ≤20 字（信息流会截断）
- 包含 1 个具体数字或 1 个明确结果，二选一
- 不堆感叹号（≤1 个）、不用"震惊/必看/速转"
- 不用 emoji 开头（信息流里 emoji 开头观感廉价）

### 1.2 标题三要素检验（写完逐条过）
- **与我有关**：目标受众看到会认为"说的是我"
- **有好处**：点进去我能得到什么（方法/清单/避坑/情绪）
- **有悬念**：信息给一半，留一半在正文（数字给但具体内容不给）

三要素缺一个 → 重写。

### 1.3 8 公式详解（组合使用效果更好）

**① 数字清单型**——最稳妥，收藏率最高
- 结构：`N 个 X + 其中最有价值的一个 + 量化收益`
- 例：「通勤穿搭 5 个公式，第 3 个显瘦 10 斤」
- 变化：「3 步」「5 招」「7 个」「10 件」

**② 痛点直击型**——精准筛选目标用户
- 结构：`用户的痛 + 原因反转/补充`
- 例：「眼妆总脏？因为你少做了这一步」
- 关键：痛点要具体（"眼妆脏"），不要泛（"化妆不好看"）

**③ 悬念钩子型**——利用"禁忌感"与好奇心
- 结构：`"千万别 X，除非 Y"`
- 例：「千万别直接涂粉底，除非你先做这步」
- 关键：Y 必须是真实有用的干货，不能是标题党（否则差评毁号）

**④ 对比反差型**——前后变化冲击力
- 结构：`以前 X → 现在 Y`（可带时间跨度）
- 例：「以前通勤天天迟到，现在提前 20 分钟出门」

**⑤ 身份代入型**——筛选同频人群
- 结构：`[某类人] 都懂/都需要的 X`
- 例：「经常加班的人都懂这双鞋」「油皮姐妹都懂这个痛」

**⑥ 反常识型**——制造认知冲突
- 结构：`越 X 越 Y` 或 `X 竟然可以 Y`
- 例：「越便宜的粉底越要这样用」
- 关键：结论必须站得住，常识反转但逻辑成立

**⑦ 提问互动型**——对话感 + 筛选
- 结构：`你会 X 吗？[数据/事实] 的人不会`
- 例：「你会选西装裤吗？90% 的人选错了」

**⑧ 结果前置型**——承诺可验证的结果
- 结构：`照着做 + 时间 + 结果`
- 例：「照着穿，一周被问 3 次链接」

### 1.4 标题与封面配合
- 标题说钩子（悬念/数字/痛点），封面大字说**同一个钩子的关键词**
- 例：标题「通勤穿搭 5 个公式，第 3 个显瘦 10 斤」→ 封面大字「第 3 个公式 显瘦 10 斤」
- 不要封面写"5 个公式"标题也写"5 个公式"——浪费封面位

## 2. 正文：滑着看的阅读体验

### 2.1 黄金三秒开头（前 3 行）

四种开头任选，**禁止寒暄**：

| 类型 | 模板 | 例 |
|---|---|---|
| 结论先行 | 「X 这件事，直接说结论：…」 | 「通勤穿搭，直接说结论：白衬衫+卡其裤永远不出错」 |
| 场景代入 | 「[场景]，你是不是也…」 | 「早高峰地铁，你是不是也随手抓了件外套就走」 |
| 问题抛出 | 「[问题]，[数据/事实]」 | 「为什么你穿西装裤显腿短？问题出在裤长」 |
| 利益声明 | 「这篇解决 [问题]，[N] 个方法直接抄」 | 「这篇解决通勤穿搭难题，5 个公式直接抄」 |

### 2.2 中段：干货分层

- 每段一个小标题句（加粗或首句点题），用户扫读也能 get 重点
- 结构模板：`要点句 → 展开 2-3 句 → 例证/数据 → （可选）小贴士`
- 干货颗粒度：给步骤编号、给具体数值、给品牌型号、给价格区间、给使用时长
- 每个核心点配 1 张图（图文笔记的图就是目录）

### 2.3 真实感细节（种草力的秘密）

用户信的不是"好"，是**细节**：
- 时间细节：「用了 3 周」「上周五实测」
- 场景细节：「通勤 1 小时地铁不闷」「开会 4 小时不脱妆」
- 对比细节：「和 200 块的对比，差距在…」
- 克制细节：「唯一的缺点是贵」「敏感肌慎入」——敢于说缺点反而更可信

### 2.4 结尾：互动引导

- 总结金句（1 句）
- 互动问题（1 个，开放型）
- 收藏引导（1 句，给理由：「先收藏，下次直接用」）
- 关注引导（1 句，给价值：「关注我，每周 3 个通勤灵感」）

## 3. 话题标签

### 3.1 格式
小红书官方格式：`#话题名称[话题]#`，写进正文末尾。

### 3.2 策略（3-5 个）
- **2-3 个精准标签**：内容核心词（如 #通勤穿搭[话题]# #上班族穿搭[话题]#）
- **1-2 个泛流量标签**：大流量池（如 #日常[话题]# #好物分享[话题]# #穿搭[话题]#）
- 不用冷门生僻标签、不用已封禁的灰产标签

## 4. 写作自检清单（交付前逐条过）

- [ ] 标题 ≤20 字，有数字或结果，三要素齐全
- [ ] 开头 3 行内进入正题，无寒暄
- [ ] 中段分点分层，每点有具体细节
- [ ] 有 1-2 个真实感细节
- [ ] 结尾有互动问题 + 收藏引导
- [ ] 话题标签 3-5 个，格式正确
- [ ] 无绝对化承诺、无敏感词、无抄袭
- [ ] 封面方向建议（与标题语义互补）

## 5. 给用户多个候选的格式模板

输出时给 3-5 个完整候选（标题 + 正文 + 标签 + 封面方向），每个候选一句话说明差异（比如"这个走情绪共鸣向""这个走干货清单向"），让用户选，选完再深化。不要只给一篇"最终答案"。
