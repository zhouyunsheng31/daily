# 小红书封面图（标题图）设计规范（详细版）

> 本文件是 `xhs-content` skill 的封面深度参考。核心一句话：**小红书封面 = 标题图，文字是主角，图是氛围**。视觉执行细节（排版/色彩/风格库）再叠加 design skill。

## 0. 为什么封面是标题图

信息流里用户 0.3 秒扫过一张 3:4 小图。此时能抓住他的只有**封面上的大字**——标题文字承担约 70% 的点击决策。所以封面设计的优先级：

```
大字标题（内容钩子） > 视觉焦点（1 个） > 色彩氛围 > 细节质感
```

## 1. 规格与安全区

- 竖版 **3:4**（信息流主展示比例；4:5 亦可）
- 建议画布 ≥ 1024×1365（2x 出图更清晰）
- **文字安全区**：画面中央 60% 区域（四周 20% 边距留给平台 UI 裁剪/圆角）
- 顶部 15% 避开（平台会叠账号信息），底部 10% 避开（叠互动栏）

## 2. 构图法则（花叔封面测试迁移）

一张好封面 = **1 个具象主角 + ≤3 个活跃元素 + 1 条视线引导**。

- 主角是产品 → 放视觉中心偏下，顶部留给文字
- 主角是场景 → 作为背景层（虚化/低饱和），文字浮在上面
- 主角是文字 → 纯色底 + 大字（大字纯色型封面，信息密度最低但辨识度最高）
- 视线引导：文字从上往下读，主体物顺着文字方向放，不逆着

**自检**：遮掉文字只剩图——构图还成立吗？（成立 = 图有主角）；遮掉图只剩文字——钩子还在吗？（在 = 字是主角）。两问都过才算合格。

## 3. 文字排版（封面设计的核心）

### 3.1 层级（最多 3 档）
| 档位 | 内容 | 字号比例（相对画布宽） | 示例 |
|---|---|---|---|
| 主标题 | 核心钩子 4-10 字 | 12-18%（大字） | 「第 3 个公式」 |
| 副信息 | 补充钩子/数字 | 6-8% | 「显瘦 10 斤」 |
| 角标 | 类型/引导 | 4-5% | 「收藏这篇」 |

### 3.2 规则
- 主标题 **字重 700+**（黑体），字距收紧（`letter-spacing: -0.02em ~ -0.05em`，大字号间隙会被放大）
- 主标题 4-10 个字最佳；**宁可大字少字，不要小字多行**
- 文字与背景**强对比**：深底白字 / 浅底深字 / 主色底反白字
- **实心字 > 描边字**：空心白字+彩色描边 = 廉价感重灾区，禁用
- 最多 2 种字体家族（1 标题 + 1 正文），中文标题优先系统黑体栈

## 4. 色彩

### 4.1 原则
- 一张图 **≤3 个主色**（1 主色 + 1 强调色 + 中性色）
- 主题色从内容里来（产品色/场景色/情绪色），不从万能渐变里来
- 情绪向内容可高对比撞色（红黑/蓝白/黄黑），生活向内容低饱和奶油系

### 4.2 参考色板（平台"纸张与墨"体系 + 小红书友好衍生）
```
暖纸底    #F8F7F3   （浅底首选）
奶油白    #FFFEFA
墨色      #171918   （深字/深底首选）
靛蓝      #315BD6   （主强调色）
墨绿      #376B53   （自然/生活向）
陶土红    #A54B49   （情绪/食欲向）
暖金      #A97F3F   （轻奢/秋日向）
```

### 4.3 反 AI slop 清单（封面语境）
- ❌ 紫渐变万能公式（除非品牌本身用）
- ❌ 贴纸堆砌（文字周围一堆小贴纸）
- ❌ emoji 当设计元素（正文可少量，封面禁用）
- ❌ 满屏渐变 + 发光字
- ❌ 无意义装饰元素（每角一个星星/圆点）
- ✅ 一个细节做到 120%（比如一个精致的角标或一条手写感下划线），其他克制

## 5. 四种封面类型模板

### 5.1 大字纯色型（干货/观点，最推荐新手）
```
纯色底（1 主色） + 中央超大标题（2-3 行内）+ 底部小字角标
例：墨绿底 + 白色大字「通勤穿搭 5 公式」+ 角标「第 3 个显瘦 10 斤」
```

### 5.2 图文分层型（种草/测评）
```
产品图/场景图占下 55% + 顶部大字标题 + 底部一条信息条（价格/型号/卖点）
中间用色块或半透明条分隔文字与图，保证可读性
```

### 5.3 对比拼图型（测评/教程）
```
左旧右新 / 上前后下前后 + 中央对角线大字结论（如「差在哪」）
两图之间留 1 条明确分隔线或色带
```

### 5.4 手写笔记感（干货/攻略）
```
浅色底（米白/淡黄）+ 手写风标题 + 清单/箭头/圈注元素
适合"抄作业"类内容，天然有收藏欲
```

## 6. 生图 Prompt 模板（AI 生成封面图时）

### 6.1 通用模板
```
小红书 3:4 竖版封面图，{构图类型：产品静物居中 / 大字海报 / 场景氛围}，
{风格：奶油系低饱和 / 高对比撞色 / 清新自然}，{光线：柔和自然光 / 窗边光}，
画面 1 个视觉焦点，{主色系：暖纸底+靛蓝强调}，留白充足适合叠加大字标题，
禁止：真人、人脸、手、动物、水印、logo、文字乱码
```

### 6.2 文字处理决策
- 生图工具能渲染中文文字 → 主标题文字直接写进 Prompt（≤10 字，强调"无错别字"）
- 生图工具文字不可靠 → **图文分离**：生成纯背景图（无文字），文字用 HTML/排版工具叠上去（更可控，推荐）
- 小红书 4:5 封面 + 文字层 = 用 HTML 做排版（文件夹方式建 App：apps/封面工具/ 下写 index.html，或 show_interactive_html），可导出 PNG

### 6.3 合规边界
- 明确排除真人/脸/手/动物：平台对 AI 生成图识别友好 + 规避肖像权
- 植物/花材/产品实物/抽象形状可作为辅助元素
- 不用知名品牌 logo、不伪造测评数据

## 7. 交付流程（给用户时的标准动作）

1. **先给 3 个封面方向**（每种一句话气质 + 色板条 + 版式示意），用户选定再执行——不用问"想要什么风格"
2. 选定后用生图/HTML 排版实现，**出图后自检**：缩小到 200px 宽看标题是否清晰可读
3. 交付时附：封面图 + 对应标题 + 排版说明（字号/色值/安全区），用户可复用改版
