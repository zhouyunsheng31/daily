# 小红书平台红线与避坑（合规参考）

> 本文件是 `xhs-content` skill 的合规底线。**任何时候都不可越过**——内容违规会导致账号限流/禁言/封号，损害用户长期利益。

## 1. 绝对化与功效承诺（最高频违规）

**禁用**：
- 医疗类：根治、治愈、药到病除、排毒、抗癌
- 减肥类：月瘦 N 斤必达、暴瘦、绝食减肥法、瘦身药
- 金融类：稳赚、保本、躺赚、无风险收益
- 功效类：100% 有效、永久、彻底、万能、零失败

**替代**：加限定词 + 个人体验口径
- ❌「3 天美白」→ ✅「我用了一个月的真实变化」
- ❌「这个面膜祛痘神器」→ ✅「痘肌姐妹可以试试这个」
- ❌「绝对不踩雷」→ ✅「目前我用下来没踩雷」

## 2. 标题党与诱导

**禁用**：
- 震惊体（震惊/太可怕/出大事了）
- 必看/速转/转发保平安
- 诱导互动（不转不是中国人、点赞过万更新）
- 标题与内容严重不符（封面诈骗）

## 3. 版权与搬运

**禁用**：
- 搬运他人图文/视频（含截图他人内容当自己素材）
- 洗稿（改写他人文案结构但实质相同）
- 使用未经授权图片（网图/品牌图/明星图）
- 抄袭他人封面设计元素

**合规**：
- 自己拍摄/制作的内容
- 注明出处的引用（短引用 + 来源）
- 平台素材库授权素材

## 4. 导流与站外行为

**禁用**：
- 私信/评论导流（微信号、QQ、淘宝店铺名、外链）
- 评论区刷量、互赞互藏群
- 冒充官方/他人账号
- 批量注册小号刷数据

## 5. AI 生成内容边界（本系统场景）

- AI 生成文案 → 用户应基于自身真实经验**审核修改后再发布**（AI 提供框架与表达，真实性由用户背书）
- AI 生成封面图 → 明确排除真人肖像（避免人脸/身形被误判为真人照），生成图不得用于虚假宣传（如"用了这个产品"的对比图必须是真实的）
- 涉及具体产品的功效描述 → 只写通用体验，不替用户编造使用数据

## 6. 敏感内容

- 政治、宗教、民族等敏感话题不创作
- 未成年人相关内容的流量玩法不做
- 惊悚/血腥/色情擦边不做
- 违规关键词清单（平台实时变化）以最新平台规则为准，拿不准就问用户确认

## 7. 自查清单（交付前）

- [ ] 无绝对化/功效承诺词
- [ ] 无震惊体/诱导话术
- [ ] 内容真实可溯源（AI 生成部分已提示用户审核）
- [ ] 无搬运/洗稿/未授权素材
- [ ] 无导流私信等站外行为
- [ ] 无敏感话题

> **一句话**：帮用户写好内容，不帮用户踩线。踩线内容火了也是毒流量，损害的是用户账号的长期价值。
