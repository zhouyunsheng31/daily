# 生活管理场景 — 完整使用链路

## 场景概述

日常生活中需要管理日程、待办事项、习惯养成、心情记录、财务储蓄等。本指南覆盖从记录事件到提醒执行的完整流程。

---

## 一、日程与待办管理

### 1.1 切换到生活面板

1. 点击工具栏 **「面板」** → 选择 **「生活」** 面板
2. 或点击坐标传送 → 点击 **「生活区」** 书签

### 1.2 手动添加日程

在 **日程列表** 组件中：

1. 点击 **「+」** 添加新日程
2. 填写信息：
   - 标题：如「后天出差去上海」
   - 开始时间：选择具体日期和时间
   - 结束时间：选择结束时间（可选）
   - 备注：补充说明（可选）
3. 保存

> **注意**：日程不支持标签，按面板隔离管理。

### 1.3 让 AI 添加日程

在 AI 助手中输入：

```
后天我要出差去上海，帮我添加一个日程提醒。
```

AI 会调用日历工具创建日程事件，弹出权限确认后即可添加。

### 1.4 让 AI 制定准备计划

```
后天要出差去上海，为期3天。帮我列一个出差准备清单。
```

AI 会：
1. 生成准备清单（身份证、充电器、换洗衣物等）
2. 在当前面板的任务列表中创建对应的待办事项
3. 在日程列表中标记出差日期

### 1.5 查看日程

日程列表支持两种视图：
- **今日视图**：查看今天的日程
- **本周视图**：查看本周的日程

切换视图：点击日程列表上方的视图切换按钮。

## 二、任务管理

### 2.1 任务列表操作

在 **任务列表** 组件中：

| 操作 | 方法 |
|------|------|
| 添加任务 | 点击「+」按钮，输入任务标题，设置优先级和截止日期 |
| 完成任务 | 点击任务前的状态图标，循环切换：待办→进行中→已完成 |
| 编辑任务 | 点击任务标题进入编辑，可修改标题、优先级、截止日期 |
| 删除任务 | 点击任务右侧的删除按钮 |
| 筛选任务 | 点击筛选按钮，选择：active/today/week/overdue/done |
| 切换视图 | 在列表视图和看板视图之间切换 |

### 2.2 任务优先级

任务支持三种优先级：
- **高**（红色）：紧急重要的事项
- **中**（黄色）：一般事项
- **低**（绿色）：不紧急的事项

### 2.3 让 AI 管理任务

```
帮我创建以下任务：
1. 今天晚上整理书包 - 高优先级
2. 明天早上交作业 - 中优先级
3. 后天出差前检查身份证 - 高优先级
```

AI 会批量创建任务，你确认权限后即可。

### 2.4 查看今日待办

```
今天我有什么任务需要完成？
```

AI 会查询当前面板的任务列表，告诉你今天到期和未完成的任务。

> **注意**：任务按面板隔离。AI 查询的是当前面板的任务，不会跨面板查询。

## 三、习惯养成

### 3.1 添加习惯

在 **习惯追踪器** 组件中：

1. 点击 **「+」** 添加新习惯
2. 填写：
   - 习惯名称：如「每天跑步30分钟」
   - 颜色：选择一个标识颜色
3. 保存

### 3.2 每日打卡

1. 打开习惯追踪器
2. 找到今天的习惯
3. 点击完成打卡

### 3.3 让 AI 追踪习惯

```
我今天跑了30分钟，帮我打卡「每天跑步」这个习惯。
```

AI 会调用习惯工具帮你记录。

### 3.4 查看习惯统计

习惯追踪器支持两种视图：
- **网格视图**：日历式打卡记录
- **列表视图**：习惯列表

---

## 四、心情记录

### 4.1 记录心情

在 **心情追踪器** 组件中：

1. 选择今天的心情等级（1-5级）
2. 可选添加备注
3. 保存

### 4.2 让 AI 记录心情

```
我今天心情不错，帮我记录一下。
```

### 4.3 查看心情趋势

心情追踪器支持两种视图：
- **日历视图**：在日历上显示每天的心情等级
- **时间线视图**：按时间线展示心情变化

---

## 五、日记

### 5.1 写日记

在 **日记** 组件中：

1. 选择日期（默认今天）
2. 在编辑区写日记内容
3. 可以添加标签
4. 自动保存

### 5.2 查看历史日记

1. 切换到 **「时间线」** 视图
2. 按时间浏览历史日记

### 5.3 让 AI 写日记摘要

```
帮我总结一下这周的日记，看看我这一周的状态如何。
```

AI 需要你授权访问日记数据后才能查看（read_private 权限）。

---

## 六、储蓄目标

### 6.1 设置储蓄目标

在 **储蓄目标** 组件中：

1. 点击 **「+」** 创建新目标
2. 填写：
   - 目标名称：如「买新手机」
   - 目标金额
   - 当前已存金额
3. 保存

### 6.2 更新进度

1. 选择目标
2. 更新已存金额
3. 查看进度条

### 6.3 让 AI 管理储蓄

```
我存了200块到买新手机的基金里，帮我更新一下进度。
```

## 八、出差/事件完整流程示例

### 场景：今天开会得知后天要出差

#### 第一步：记录事件

在 AI 助手中输入：

```
今天开会得知后天要出差去上海，为期3天，参加技术交流会。帮我做好安排。
```

#### 第二步：AI 制定计划

AI 会：
1. 在日程列表中添加出差日程（后天的日期）
2. 在当前面板的任务列表中创建准备清单：
   - ○ 订机票（高优先级）
   - ○ 订酒店（高优先级）
   - ○ 准备出差材料（中优先级）
   - ○ 检查身份证（高优先级）
   - ○ 收拾行李（中优先级）
3. 可选：添加倒计时卡片

#### 第三步：确认权限

AI 创建日程和任务时需要你确认权限，逐一允许即可。

#### 第四步：逐项完成

1. 订完机票后，点击任务前的状态图标将「订机票」标记为已完成
2. 订完酒店后，标记「订酒店」为已完成
3. 以此类推

#### 第五步：出差当天

1. 打开项目，切换到生活面板
2. 查看日程列表，出差日程显示在今日视图中
3. 检查任务列表，确认所有准备工作已完成
4. 如有遗漏，快速处理

#### 第六步：出差回来后

1. 标记所有出差任务为已完成
2. 写日记记录出差经历
3. 记录心情

## 九、提醒与状态总览

### 9.1 综合状态查看

每天打开项目后，通过以下方式快速了解今日状态：

1. **日程列表**：切换到「今日」视图，查看今天有什么安排
2. **任务列表**：筛选 **「today」** 查看今天到期的任务
3. **习惯追踪器**：查看今天需要打卡的习惯
4. **倒计时卡片**：查看重要日期的倒计时

### 9.2 让 AI 做每日总结

```
帮我总结一下今天的状态：有什么日程、待办任务、需要打卡的习惯。
```

AI 会综合查询多个数据源（需授权），给你一个完整的今日概览。

> **注意**：AI 查询私人数据（日记、心情等）需要你先授权。在 AI 助手的上下文面板中可以管理已授权的数据源。

### 9.3 统计面板

打开 **统计面板** 组件，可以查看：
- **总览**：整体数据概览
- **专注**：专注时间统计
- **习惯**：习惯完成率
- **心情**：心情变化趋势

## 十、生活场景与学习场景的联动

### 10.1 面板隔离

任务和日程按面板隔离，这意味着：
- 在学习面板创建的学习任务不会出现在生活面板
- 在生活面板创建的生活日程不会出现在学习面板
- 这保证了每个场景的独立性

### 10.2 全局共享的数据

以下数据是全局共享的（不按面板隔离）：
- 错题本
- 单词记忆词库和进度
- AI 记忆

### 10.3 快速切换

使用坐标传送的书签功能，一键从学习区跳转到生活区：
1. 点击坐标传送 → 点击「生活区」书签
2. 或点击坐标传送 → 点击「学习区」书签返回

### 10.4 AI 跨场景操作

AI 助手可以操作当前面板的数据。如果你需要跨面板操作，需要先切换到对应面板。

```
我学完数学了，帮我看看生活面板还有什么事情要做。
```

> **注意**：AI 默认只能操作当前面板的数据。如需查看其他面板的任务，需要先切换面板。
