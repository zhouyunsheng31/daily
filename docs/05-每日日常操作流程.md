# 每日日常操作流程 — 从第一天到每一天

## 一、第一天（首次使用）

### 1.1 启动

```bash
cd f:\allmylife\event
npm run dev
```

浏览器打开 `http://localhost:5173`

### 1.2 初始配置（约10分钟）

1. **配置 AI 助手**
   - 添加 AI 助手组件 → 接受隐私声明 → 在上下文面板中配置 API Key → 测试发送消息
   - 详见 [01-首次启动与初始配置.md](01-首次启动与初始配置.md)

2. **创建面板**
   - 新建「学习」面板
   - 新建「生活」面板
   - 新建「休闲」面板

3. **搭建学习面板布局**
   - AI 助手（左侧大区域）
   - 任务列表（右上）
   - LaTeX 出题器（右中）
   - 错题本（右下）
   - 专注计时器（左下角）

4. **搭建生活面板布局**
   - AI 助手（左侧）
   - 日程列表（右上）
   - 任务列表（右中）
   - 日记（右下）
   - 习惯追踪器（左下）

5. **搭建休闲面板布局**
   - 音乐播放器（左上）
   - 数独（右上）
   - 呼吸练习（左下）

6. **保存书签**
   - 每个面板保存一个书签：「学习区」「生活区」「休闲区」

### 1.3 第一次学习（约30分钟）

1. 切换到学习面板
2. 在 AI 助手中输入：
   ```
   我是高二学生，请帮我制定一个今天的学习计划。我需要复习数学和英语。
   ```
3. 确认 AI 创建的任务
4. 开始做题：
   - 打开专注计时器
   - 让 AI 出数学题
   - 做题、对答案
5. 完成后点击任务前的状态图标，将任务标记为已完成

### 1.4 第一次生活记录（约5分钟）

1. 切换到生活面板
2. 在习惯追踪器中添加日常习惯：
   - 每天跑步30分钟
   - 每天背50个单词
   - 每天10点前睡觉
3. 记录今天的心情（1-5级）
4. 写一段日记

### 1.5 关闭

直接关闭浏览器即可，所有数据自动保存在 IndexedDB 中。

---

## 二、第二天（日常开始）

### 2.1 早上起床后（约5分钟）

1. 启动项目：`npm run dev`，打开浏览器
2. 切换到生活面板
3. 在 AI 助手中输入：
   ```
   今天有什么任务和日程？帮我做个今日概览。
   ```
4. AI 会告诉你：
   - 当前面板今天到期的任务
   - 今天的日程安排
   - 需要打卡的习惯（需授权习惯数据）
5. 根据概览规划今天

### 2.2 上学前（约5分钟）

1. 打开单词记忆，复习到期的单词
2. 快速浏览错题本中今天到期的复习项

### 2.3 放学后（约2小时）

1. 切换到学习面板
2. 在任务列表中筛选 **「today」** 查看今天的学习任务
3. 开始学习：
   ```
   AI，我今天要复习物理和数学，帮我安排一下。
   ```
4. 按计划执行：
   - 开启专注计时器
   - 做题练习
   - 错题记录
5. 完成后点击任务状态图标标记为已完成

### 2.4 休息时间（约15分钟）

1. 坐标传送 → 「休闲区」
2. 听几首歌或玩一局数独
3. 做几分钟呼吸练习
4. 坐标传送 → 「学习区」继续学习

### 2.5 睡前（约10分钟）

1. 切换到生活面板
2. 打卡今天的习惯
3. 记录今天的心情
4. 写日记（可以简短）
5. 让 AI 总结今天：
   ```
   总结一下我今天的学习和生活情况。
   ```

## 三、有特殊事件的日子

### 3.1 考试前一天

1. 切换到学习面板
2. 让 AI 帮你做最后冲刺：
   ```
   明天要考数学了，帮我做最后的复习。重点看错题本里的错题。
   ```
3. 复习错题本
4. 做几道模拟题
5. 早点休息

### 3.2 出差/外出日

1. 切换到生活面板
2. 查看出差相关任务
3. 确认准备工作已完成
4. 添加临时任务（如「到达后给家里报平安」）

### 3.3 周末

1. 上午：集中学习（2-3小时）
2. 下午：休闲放松
3. 晚上：
   - 总结本周学习情况
   - 制定下周计划
   - 复习本周错题

---

## 四、每周例行

### 4.1 周日晚上

1. 让 AI 做周总结：
   ```
   帮我总结这周的学习和生活情况，包括完成了多少任务、学习时长、习惯完成率。
   ```
2. 查看统计面板的数据
3. 制定下周计划：
   ```
   帮我制定下周的学习计划，重点复习期中考试范围。
   ```
4. 清理已完成的旧任务

---

## 五、每月例行

### 5.1 月初

1. 查看统计面板的月度数据
2. 评估上个月的目标完成情况
3. 设定本月目标
4. 更新储蓄目标进度

### 5.2 月末

1. 写月度总结日记
2. 导出数据备份：设置 → 数据管理 → 导出数据
3. 清理过期的日程和任务

---

## 六、数据备份与恢复

### 6.1 导出数据

1. 点击工具栏 **「设置」** 按钮
2. 切换到 **「数据管理」** 标签页
3. 点击 **「导出数据」**，会下载一个 JSON 文件
4. 保存到安全位置

### 6.2 导入数据

1. 点击工具栏 **「设置」** 按钮
2. 切换到 **「数据管理」** 标签页
3. 选择之前导出的 JSON 文件
4. 确认导入

### 6.3 建议备份频率

- 每周备份一次
- 重要考试前备份
- 大量数据变更后备份

## 七、常见问题

### Q: AI 不回复怎么办？

1. 检查网络连接
2. 检查 API Key 是否正确（在 AI 助手的上下文面板中查看）
3. 检查 API 端点是否可用
4. 尝试切换模型
5. 查看 AI 助手头部是否显示「离线」

### Q: 数据丢失了怎么办？

1. 检查是否清除了浏览器数据
2. 尝试从备份文件导入（设置 → 数据管理 → 导入数据）
3. 检查是否在正确的浏览器中打开

### Q: 组件太多画布太乱怎么办？

1. 使用面板隔离不同场景
2. 使用坐标传送在不同区域间跳转
3. 保存书签方便快速定位
4. 删除不需要的组件

### Q: AI 权限确认太频繁怎么办？

1. 对于私人数据读取（read_private），授权后该数据源会被记住，后续不再需要每次确认
2. 在 AI 助手的上下文面板中可以查看和管理已授权的数据源
3. 写操作和危险操作始终需要确认（安全设计，无法跳过）

### Q: 如何在手机上使用？

1. 项目是 Web 应用，手机浏览器也可以访问
2. 启动时使用 `npm run dev -- --host` 开放局域网访问
3. 手机连同一 WiFi，访问电脑的局域网 IP:5173
4. 界面可能需要适配移动端
