## 一、概述

### 1.1 产品定位

**形态**：浏览器 + 无限画布 + AI

**用途**：日常 AI 助手

Living Dashboard 是一款融合浏览器与无限画布的 AI 助手产品。它既是浏览器（上网工具），又是画布（个人数据管理），核心是贯穿两者的 AI 能力。产品包含桌面端（Electron + React + TypeScript）和移动端（Kotlin + Jetpack Compose + WebView），双端共享服务器数据，实现多端互通。

> 移动端布局设计见 [layout-design-mobile.md](layout-design-mobile.md)

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **对称设计** | 浏览器主页与画布主页在布局上对称（pill 搜索框↔pill AI 输入框、Logo↔圆形图标、书签圆形网格↔收藏组件网格），降低学习成本 |
| **原生优先** | 桌面端用 Electron 原生渲染，移动端用 Kotlin + Compose 原生 UI，保证丝滑体验 |
| **轻量优先** | 移动端复用系统 WebView，包体 < 20MB；桌面端 tree-shaking 图标 |
| **多端互通** | 共享服务器数据库，面板/组件/AI 对话/书签/脚本/收藏组件跨端同步 |
| **透明优先** | 组件不使用实线边框，以半透明背景和毛玻璃效果区分层次，营造轻盈通透的视觉感受 |

**与移动端的对应关系**：桌面端 App Shell 对应移动端的 BottomBar 导航框架。桌面端的顶部栏 + 侧边栏功能在移动端被重新组织为底部栏 + 更多菜单。

## 四、双端对比矩阵

### 4.1 页面双端对应关系

| 功能域 | 桌面端页面 | 移动端页面 | 对应关系 |
|--------|-----------|-----------|---------|
| 整体框架 | App Shell（顶部栏+侧边栏+主区域） | App Shell（BottomBar+导航图） | 结构重组 |
| 浏览器主页 | BrowserHome | BrowserHomeScreen | 功能对等，桌面端有预览模式 |
| 画布主页 | CanvasHome | CanvasHomeScreen（规划中） | 功能对等，移动端有聚合面板入口 |
| 网页浏览 | WebTabFullscreen | BrowserScreen | 功能对等，地址栏位置不同 |
| 画布操作 | Workspace + UnifiedToolbar | CanvasScreen（规划中） | 功能对等，交互方式不同 |
| 标签管理 | TabBar（内嵌在顶部栏） | TabManagerScreen（独立页面） | 形态不同，功能对等 |
| 面板管理 | Sidebar（左侧常驻） | TabManagerScreen（统一管理） | 形态不同，功能对等 |
| 书签管理 | BrowserHome 内嵌 | BookmarkScreen（独立页面） | 形态不同，功能对等 |
| 历史记录 | 无独立页面 | HistoryScreen（独立页面） | 桌面端缺失 |
| 设置 | SettingsPanel（抽屉覆盖层） | SettingsScreen（独立页面） | 形态不同，功能对等 |
| AI 快速输入 | GlobalQuickInput（左 Alt） | 底部栏 AI 输入框模式（上滑） | 触发方式不同 |
| 组件搜索 | WidgetSearch（Ctrl+F） | 无 | 移动端缺失 |
| 小地图 | Minimap（画布右下角） | 无 | 移动端缺失 |
| 更多菜单 | 右键菜单 + SettingsPanel | MoreMenuSheet（半屏面板） | 形态不同 |
| WebOS 组件页 | 无（直接跳转画布位置） | WebOSWidgetScreen（规划中） | 移动端独有 |
| 聚合面板 | 无 | AggregatePanelScreen（规划中） | 移动端独有 |

| 页面背景 | 纯白 #ffffff 或极浅灰 #fafafa |
| 组件卡片 | rgba(0,0,0,0.03) 半透明背景，无边框 |
| 搜索框/输入框 | rgba(0,0,0,0.04) 半透明背景，聚焦时 rgba(0,0,0,0.06) |
| 消息气泡 | 用户消息 rgba(0,0,0,0.05)，AI 回复 rgba(0,0,0,0.03) |
| 工具栏/底栏 | rgba(255,255,255,0.85) 毛玻璃，无边框 |
| 侧边栏 | rgba(255,255,255,0.6) 毛玻璃，无边框 |
| 分割线 | rgba(0,0,0,0.06)，1px |
| 文字 | #1d1d1f 主文字，#86868b 辅助文字 |

核心原则：无边框、半透明背景、毛玻璃效果、白色为主。

## 七、响应式策略

### 7.1 桌面端窗口缩放行为

| 窗口宽度 | Sidebar | 主区域 | TabBar | UnifiedToolbar |
|---------|---------|--------|--------|---------------|
| >= 1200px | 展开（240px，可拖拽调整 48-400px） | 充裕 | 完整显示 | 单行 |
| 1000px - 1200px | 可手动折叠，可拖拽调整 | 适中 | 标签宽度自适应 | 单行 |
| 800px - 1000px | 折叠为图标条（48px），可拖拽展开 | 较宽 | 标签紧凑显示 | 可能换行 |
| < 800px | 自动折叠，可拖拽展开 | 宽裕 | 仅显示图标 | 紧凑模式 |

> 所有宽度区间均支持通过拖拽分割线调整 Sidebar 宽度和 Omnibox/TabBar 高度比例。

**最小窗口**：建议 800 x 600px。低于此宽度时 Sidebar 强制折叠，TabBar 标签仅显示图标。
