# 学考学习场景 — 完整使用链路

## 场景概述

你是高二学生，需要用这个项目进行日常学习、备考刷题、错题管理。本指南覆盖从制定学习计划到做题、复习的完整流程。

---

## 一、制定学习计划

### 1.1 打开学习面板

1. 启动项目：`npm run dev`，浏览器打开 `http://localhost:5173`
2. 点击工具栏 **「面板」** → 选择 **「学习」** 面板
3. 或点击坐标传送 → 点击 **「学习区」** 书签

### 1.2 让 AI 制定计划

在 AI 助手中输入：

```
我是高二学生，马上要期中考试了，请帮我制定一个数学复习计划。
我的薄弱点是：函数与导数、立体几何。
每天大约能学2小时。
```

AI 会：
1. 分析你的需求
2. 生成一个结构化的复习计划
3. **自动调用工具**在任务列表中创建对应的任务（需你确认权限）

### 1.3 确认 AI 的工具调用

当 AI 要操作任务列表时，会弹出权限确认对话框：

- **读取操作**（read_public）：自动通过
- **读取私人数据**（read_private）：弹出确认框，询问是否授权访问该数据源
- **写入操作**（write）：弹出确认框，显示 AI 要做什么，点击 **「确认执行」**
- **危险操作**（dangerous）：需要二次确认，输入"确认"才能执行

确认后，AI 会在当前面板的任务列表中创建类似这样的任务：

- ○ 复习函数基本性质（高优先级）
- ○ 练习导数计算（中优先级）
- ○ 复习立体几何定理（中优先级）
- ○ 做函数与导数综合题（高优先级）

### 1.4 任务管理说明

> **重要**：任务列表按面板隔离。在学习面板创建的任务只出现在学习面板的任务列表中，不会出现在生活面板。这实现了学习场景与其他场景的独立性。

任务列表支持的筛选方式：
- **active**：进行中的任务
- **today**：今天到期的任务
- **week**：本周到期的任务
- **overdue**：已过期的任务
- **done**：已完成的任务

任务列表支持的视图：
- **列表视图**：按优先级和到期时间排列
- **看板视图**：按状态分三列（待办/进行中/已完成）

## 二、数学做题流程

### 2.1 使用 LaTeX 出题器

#### 方式一：直接使用出题器组件

1. 在学习面板找到 **LaTeX 出题器** 组件
2. 选择题目分类：
   - `algebra`（代数）
   - `geometry`（几何）
   - `calculus`（微积分/导数）
   - `trig`（三角函数）
3. 点击开始，出题器会逐题显示
4. 逐题填写答案，按 Enter 提交当前答案并跳到下一题
5. **全部答完后**，点击 **「结束并判分」** 按钮查看结果

> **注意**：LaTeX 出题器不是逐题判分，而是全部答完后统一判分。

#### 方式二：让 AI 出题（推荐）

在 AI 助手中输入：

```
给我出一道导数题，先告诉我相关的基础概念和方法，然后出题。
```

AI 会：
1. 先讲解基础概念（如导数的定义、求导法则）
2. 出一道题给你
3. 你输入答案后，AI 判断对错
4. AI 可以写代码验证数学题的正确性（通过工具调用）

### 2.2 做题交互流程

```
你：给我出一道函数单调性的题

AI：好的，先回顾一下基础概念：
    函数单调性的判断方法：
    1. 定义法：取x1<x2，比较f(x1)和f(x2)
    2. 导数法：f'(x)>0则递增，f'(x)<0则递减

    题目：求函数 f(x) = x³ - 3x 的单调区间。

你：f'(x) = 3x² - 3 = 3(x+1)(x-1)
    令f'(x)>0：x<-1或x>1，递增
    令f'(x)<0：-1<x<1，递减
    所以递增区间是(-∞,-1)和(1,+∞)，递减区间是(-1,1)

AI：正确！你的解答完全正确。
    递增区间：(-∞,-1)∪(1,+∞)
    递减区间：(-1,1)
```

### 2.3 错题自动记录

当做错题目时：

1. **LaTeX 出题器**：答错的题会自动记录到错题本（来源标记为 `LaTeX 出题器`）
2. **AI 出题**：目前 AI 出题的错题不会自动进入错题本（错题本来源仅支持 LaTeX 出题器）。你可以手动在错题本中添加错题记录，或将题目和答案复制到便签中保存

错题本中记录的信息包括：
- 题目内容
- 你的错误答案
- 正确答案
- 解析说明
- 来源（目前支持 `LaTeX 出题器`）
- 下次复习时间（基于 SM2 间隔重复算法自动计算）

## 三、高考真题练习

### 3.1 让 AI 搜索真题

在 AI 助手中输入：

```
请搜索2025年高考数学真题，找几道函数与导数的题目给我做。
```

> **注意**：AI 的搜索能力取决于其模型本身的知识和联网能力。当前默认的 deepseek-v4-flash 模型可能无法实时联网搜索。如果需要搜索功能，请确认你的 API 服务支持联网，或切换到支持联网的模型。

### 3.2 AI 改编真题

```
请根据2024年高考数学全国I卷的导数大题，改编一道类似的题目给我做，难度相当但数据不同。
```

AI 可以基于其训练数据中的高考真题进行改编出题。

### 3.3 模拟考试模式

1. 打开 **专注计时器**，设置 30 分钟
2. 让 AI 连续出 5 道题
3. 限时作答
4. 完成后让 AI 批改并总结

## 四、错题本管理

### 4.1 查看错题列表

1. 找到 **错题本** 组件
2. 默认显示所有错题列表
3. 可以按来源筛选（目前支持「全部来源」和「LaTeX 出题器」）

### 4.2 复习错题

1. 切换到 **「复习」** 模式
2. 系统会根据 SM2 算法安排需要复习的错题
3. 查看题目，尝试重新作答
4. 点击 **「显示解析」** 查看正确答案和解析
5. 点击 **「掌握了」** 或 **「还没掌握」** 按钮，系统会根据 SM2 算法调整下次复习时间

### 4.3 查看统计

1. 切换到 **「统计」** 模式
2. 查看错题数量趋势、正确率等数据

---

## 五、单词/词汇学习

### 5.1 使用词汇训练器

1. 找到 **单词记忆** 组件
2. 选择或创建一个词库（如「高中英语3500词」）
3. 进入 **「学习」** 模式：逐个学习新单词
4. 进入 **「复习」** 模式：复习到期需要复习的单词
5. 进入 **「统计」** 模式：查看学习进度

### 5.2 让 AI 辅助背单词

```
帮我复习今天到期的英语单词，先显示单词，我说出意思后再显示答案。
```

AI 可以调用词汇相关工具，获取你的学习进度和到期单词。

---

## 六、专注学习

### 6.1 使用专注计时器

1. 找到 **专注计时器** 组件
2. 设置专注时长（默认 25 分钟，番茄工作法）
3. 点击开始
4. 专注期间不要做其他事
5. 计时结束会有提示
6. 可以关联到具体任务

### 6.2 让 AI 管理专注

```
我要开始学习数学了，帮我开启一个25分钟的专注计时。
```

AI 会调用专注工具帮你开始计时。

---

## 七、学习场景的独立性

### 7.1 面板隔离

学习面板和生活面板是完全独立的：
- **任务列表按面板隔离**：在学习面板创建的任务只出现在学习面板，不会出现在生活面板
- **日程列表按面板隔离**：同理，日程也是按面板分开的
- **错题本是全局共享的**：错题本数据不按面板隔离，所有面板都能看到
- **单词记忆是全局共享的**：词库和进度不按面板隔离

### 7.2 快速切换场景

1. 使用 **坐标传送** → 点击书签快速跳转
2. 使用 **面板菜单** → 切换面板
3. 快捷方式：在学习面板保存书签「学习区」，在生活面板保存书签「生活区」

## 八、每日学习流程

### 放学后（约18:00）

1. 打开项目，切换到学习面板
2. 查看 AI 助手，让它总结今天需要完成的学习任务：
   ```
   今天有什么学习任务需要完成？
   ```
3. 按计划逐项完成：
   - 打开专注计时器
   - 做题（LaTeX出题器或AI出题）
   - 错题自动记录
4. 完成后点击任务前的状态图标，将任务标记为已完成

### 睡前（约22:00）

1. 打开错题本，复习今天到期的错题
2. 打开单词记忆，复习到期的单词
3. 让 AI 总结今天的学习情况

### 第二天早上

1. 打开项目，切换到学习面板
2. 在任务列表中筛选 **「today」** 查看今天到期的任务
3. 开始新一天的学习
