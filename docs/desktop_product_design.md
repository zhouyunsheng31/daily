## 一、产品定位

**形态上是"浏览器 + 无限画布 + AI"，功能用途上是日常 AI 助手。**

- 既是浏览器（上网工具）
- 又是画布（个人数据管理）
- **核心是日常 AI 助手**（AI 贯穿浏览器和画布，随时可用）
- AI 贯穿两者，可操控浏览器/画布/组件
- 与移动端数据互通

## 二、整体布局

```
┌─────────────────────────────────────────┐
│ [Omnibox]  [网页标签1📌][网页标签2][+]    │  ← 顶部：地址栏(左) + 网页标签
├──────┬──────────────────────────────────┤
│Sidebar│  主区域（单一显示）               │
│面板库 │  网页 / 画布 / 主页              │
│[面板1]│                                  │
│[面板2]│  UnifiedToolbar（仅画布模式）     │
│[+新建]│                                  │
└──────┴──────────────────────────────────┘
```

### 2.1 顶部 TabBar（网页标签管理）

- **位置**：顶部，Omnibox 右侧
- **内容**：网页标签列表 + 新建按钮（+）
- **标签元素**：标题 + ❌关闭 + 📌嵌入按钮
- **新建标签**：→ 浏览器主页
- **交互**：点击切换、拖拽重排、中键/右键关闭、双击重命名

### 2.2 左侧 Sidebar（画布面板管理）

- **位置**：左侧，可折叠
- **内容**：画布面板列表 + 新建按钮（+）
- **新建面板**：→ 画布主页
- **交互**：点击切换、右键重命名/删除/复制/转换为网页组件

### 2.3 Omnibox（地址栏）

- **位置**：左上角小区域
- **功能**：URL 导航 / 搜索 / `ai:` 对话 / `/new-panel` `/open` 斜杠命令
- **快捷键**：Ctrl+L 聚焦

### 2.4 主区域（单一显示）

- **同一时间只显示一个**：网页 / 画布 / 主页
- **点网页标签**：主区域显示该网页
- **点画布面板**：主区域显示该画布
- **点新建**：主区域显示对应主页

### 2.5 UnifiedToolbar（底部浮动工具栏）

- **仅画布模式显示**（浏览网页时隐藏）
- **内容**：画布模式工具（选择/拖动/画笔/橡皮/连线）+ 撤销重做 + 添加组件 + 缩放 + 传送 + 全屏 + 视图 + 设置

## 三、两种主页

对齐移动端设计，但利用桌面端大屏空间展示更多预览内容。

### 3.1 浏览器主页

```
┌─────────────────────────────────────────┐
│                                         │
│         🔍 搜索框                       │
│         [Logo/书签一体]                 │
│                                         │
│   📌 常用网站（可直接预览网站）          │
│   ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐     │
│   │贴吧 │ │知乎 │ │B站  │ │ +   │     │
│   │预览 │ │预览 │ │预览 │ │添加 │     │
│   └─────┘ └─────┘ └─────┘ └─────┘     │
│                                         │
│   📑 书签入口                           │
│                                         │
```

- **搜索框**：输入网址或搜索
- **Logo/书签一体**：Via 风格
- **常用网站**：书签标记"显示在主页"，**可直接预览网站**（桌面端大屏优势）
- **可自定义**：背景图、Logo、主题色

### 3.2 画布主页

```
┌─────────────────────────────────────────┐
│                                         │
│         ⭕ 圆形图标                     │
│         💬 AI 对话框                    │
│                                         │
│   ⭐ 收藏组件（可直接预览组件）          │
│   ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐     │
│   │待办 │ │笔记 │ │计算器│ │ +   │     │
│   │预览 │ │预览 │ │预览 │ │添加 │     │
│   └─────┘ └─────┘ └─────┘ └─────┘     │

│   📑 收藏组件入口                       │

└─────────────────────────────────────────┘
```

- **圆形图标**：AI 对话框上方，可替换
- **AI 对话框**：类 Tabbit，不创建组件，可导航/创建面板
- **收藏组件**：**可直接预览组件**（桌面端大屏优势），点击跳转到对应面板的对应组件位置
- **可自定义**：背景图、圆形图标、主题色（可与浏览器主页不同）

### 3.3 两种主页的对称关系

| 浏览器主页 | 画布主页 |
|-----------|---------|

| Logo/书签一体 | 圆形图标（对话框上方） |
| 常用网站（可预览） | 收藏组件（可预览） |
| 书签入口 | 收藏组件入口 |

## 四、导航逻辑

### 4.1 没有 Home 键

桌面端没有 Home 键（正常浏览器没有 Home 键说法）。通过**新建标签/面板**进入对应主页：
- 新建网页标签 → 浏览器主页
- 新建画布面板 → 画布主页

### 4.2 标签/面板切换

- **点上方网页标签**：主区域切换到该网页
- **点左侧画布面板**：主区域切换到该画布
- **主区域单一显示**：同一时间只显示一个（网页或画布）

### 4.3 网页与画布的双向转换

保留现有机制（`convertWidgetToTab` / `convertTabToWidget`）：

- **网页标签 → 画布组件**：点网页标签的 📌嵌入按钮 → 在当前画布创建 WebviewWidget 组件，**网页标签不关闭**（引用关系，数据同步）
- **画布组件 → 网页标签**：WebviewWidget 可转换为网页标签（现有 `convertWidgetToTab`）

### 4.4 嵌入按钮（📌）

- **位置**：网页标签上，❌关闭按钮旁边
- **行为**：点嵌入 → 在当前画布面板创建 WebviewWidget 组件
- **网页标签不关闭**：网页在标签页和画布组件中同时存在，共享数据（引用关系）
- **类似移动端收藏组件**：引用不是复制，数据同步

## 五、去掉的东西

### 5.1 desktop appMode

**现状**：`appMode: 'canvas' | 'desktop'`，desktop 模式隐藏画布 AI widget + 显示底部 DesktopChatBar。

**决策**：**去掉 desktop 模式**，统一为一种模式。

**原因**：
- desktop 模式命名与"桌面端"混淆
- 浏览器与画布五五开后，不需要单独的 desktop 模式
- AI 入口统一为：画布上的 AIAssistant widget + Omnibox 的 `ai:` 命令 + GlobalQuickInput（左 Alt 唤起）

### 5.2 DesktopChatBar

**现状**：desktop 模式下底部显示的 AI 对话栏。

**决策**：**去掉**（随 desktop 模式一起去掉）。

### 5.3 Home 键

**决策**：**不需要**。通过新建标签/面板进入主页。

## 六、AI 入口

桌面端 AI 入口（去掉 desktop 模式后）：

| 入口 | 位置 | 说明 |
|------|------|------|
| **AIAssistant widget** | 画布上 | 每个面板独立的 AI 助手组件 |

| **GlobalQuickInput** | 左 Alt 唤起 | 全局快速 AI 输入 |
| **画布主页 AI 对话框** | 画布主页 | 类 Tabbit，可导航/创建面板 |

## 七、内存管理与休眠策略

**双端统一策略**（详见移动端 roadmap 3.8 节）：

| 状态 | 触发条件 | 行为 | 恢复速度 |
|------|---------|------|---------|
| **活跃** | 当前面板/标签 | 完整渲染 | - |
| **后台** | 切换到其他 | webview `stop()`，状态保留内存 | 快（秒级） |
| **休眠** | 后台超 5 分钟 / 内存达阈值 | 释放 webview，数据存数据库 | 中（1-2 秒） |
| **深度休眠** | 内存压力大（桌面端 >1GB） | 只保留元数据 | 慢（2-3 秒） |

**桌面端现状改进**：当前所有面板同时渲染，非活跃面板 webview `stop()` 但组件实例和 React 状态仍在内存。需改为：非活跃面板超过阈值时卸载组件树，只保留数据。

| 维度 | 桌面端 | 移动端 |

## 十、UI 图标方案

### 10.1 图标库

**方案**：`lucide-react`（轻量 SVG 图标库，tree-shaking）

```bash
npm install lucide-react
```

```tsx
import { Home, Search, ArrowLeft, ArrowRight, Plus, X, Pin } from 'lucide-react';

// 使用
<Home size={20} color="currentColor" />
<Pin size={16} />
```

**优势**：
- Tree-shaking，只打包用到的图标
- SVG 矢量，任意缩放
- 支持 tint（color 属性）
- 体积小（单图标 ~1KB）
- 风格统一（线性图标，现代风格）

### 10.2 常用图标映射

| 用途 | lucide-react 图标 |
|------|------------------|
| 后退 | ArrowLeft |
| 前进 | ArrowRight |
| 刷新 | RotateCw |
| 新建 | Plus |
| 关闭 | X |
| 嵌入 | Pin |
| 主页 | Home |
| 搜索 | Search |
| 标签页 | Square |
| 菜单 | MoreVertical |
| 设置 | Settings |
| 缩放 | ZoomIn / ZoomOut |
| 画布模式 | MousePointer2 |
| 画笔 | Pen |

### 10.3 Logo

- 用 SVG 或 WebP，放 `client/desktop/src/assets/`

### 10.4 禁用方案

## 十一、架构要点

详见 [architecture_refactor.md](file:///f:/allmylife/event/docs/architecture_refactor.md)：

- **AI 推理**：保持服务器（Pi Agent 在服务器）
- **AI 上下文**：按面板共享（同一面板多端共享，不同面板独立）
- **多端并行**：按面板路由工具调用，不同面板可并行
- **冲突解决**：乐观锁 + 冲突提示
- **动态组件跨端**：纯前端组件可跨端，依赖本地环境组件需标记或服务器中转
