# Living Dashboard 桌面端 用户手册

> 生成日期：2026-06-26（Phase 7 批次7）
> 适用版本：v0.7.0-phase7
> 配套文档：[layout-design-desktop.md](layout-design-desktop.md)、[developer-guide.md](developer-guide.md)

Living Dashboard 是一款融合「浏览器 + 无限画布 + AI 助手」的桌面端应用。本文档面向最终用户，介绍安装、界面、功能与设置。

---

## 一、快速入门

### 1.1 安装与启动

- **Windows 安装包**：双击 `Living Dashboard Setup.exe`，按向导完成安装后，从开始菜单启动。
- **免安装版**：解压 `Living Dashboard-x.x.x-win.zip` 到任意非 C 盘目录，双击 `Living Dashboard.exe` 启动。
- **开发模式**：在项目根目录执行 `npm run dev` 启动 Electron 开发服务器。

> 首次启动会创建本地数据库（IndexedDB）与配置文件，无需手动初始化。

### 1.2 首次使用引导

1. 启动后默认进入「浏览器主页」，可在顶部地址栏输入网址或搜索词。
2. 左侧侧边栏列出画布面板，点击 `+ 新建` 创建第一个画布面板。
3. 在画布主页可点击中央的 pill 形 AI 输入框与 AI 对话，或点击 `进入画布` 开始摆放组件。
4. 点击右上角设置图标（或快捷键 `Ctrl+,`）打开设置面板，配置主题、AI、服务器等。

## 二、界面概览

整体框架由「顶部工具栏 + 侧边栏 + 主区域」组成，所有面板之间用可拖拽分割线分隔。

### 2.1 顶部工具栏

- **Omnibox（地址栏）**：输入 URL 直接访问；输入非 URL 文本则用默认搜索引擎搜索。
- **TabBar（标签栏）**：管理网页标签，每个标签显示标题与 favicon；标签上的 📌 按钮可将当前网页嵌入到画布。
- **可拖拽水平分割线**：拖动可调整 Omnibox 与 TabBar 的宽度比例，双击重置为默认比例。

### 2.2 侧边栏

- 画布面板列表，点击切换面板。
- 顶部 `+` 按钮新建画布面板。
- 底部按当前面板显示收藏组件入口。
- 侧边栏右侧有可拖拽垂直分割线，拖动可调整宽度（48–480px），双击重置。

### 2.3 主区域（依据 `mainView.type` 切换）

| 视图 | 触发 | 说明 |
|------|------|------|
| 浏览器主页（browser-home） | 新建网页标签 | Logo + pill 搜索框 + 书签圆形图标网格 |
| 网页全屏（web-tab） | 点击标签或书签 | 全屏 WebView 加载网页 |
| 画布主页（canvas-home） | 新建画布面板 | 圆形图标 + 收起式 AI 输入框 + 收藏组件网格 |
| 画布面板（canvas-panel） | 进入画布 | 无限画布 + 浮动工具栏 + 小地图 |

### 2.4 AI 输入框（收起式）

画布主页中央的 pill 形输入框：

- **收起态**：高度 48px，placeholder 为「有什么想问的...」，左侧显示在线/离线小圆点（绿色在线 / 红色离线）。
- **展开态**：点击或聚焦后展开为对话区域，消息气泡直接浮在页面上，底部固定输入框；右上角悬浮设置与关闭按钮。
- 点击输入框外部可收起；收起/展开不丢失已输入内容与历史消息。

## 三、浏览器功能

### 3.1 网页浏览

| 操作 | 入口 |
|------|------|
| 新建标签 | TabBar 末尾 `+` 按钮，或快捷键 `Ctrl+T` |
| 关闭标签 | 标签上的关闭按钮，或快捷键 `Ctrl+W`（由主进程拦截，不会关闭窗口） |
| 恢复关闭的标签 | 快捷键 `Ctrl+Shift+T`（会话级，最多恢复 10 条） |
| 切换标签 | 点击标签；`Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换；`Ctrl+1..9` 切换到第 N 个 |
| 网页后退 / 前进 | `Alt+←` / `Alt+→` |
| 刷新网页 | `Ctrl+R` 或 `F5`（由主进程拦截，仅刷新当前 webview，不刷新整个窗口） |
| 嵌入到画布 | 标签上的 📌 按钮，将网页作为 WebviewWidget 组件添加到当前画布面板 |

### 3.2 书签管理

- 在浏览器主页点击 `+ 添加` 圆形图标，输入 URL + 名称即可加入书签。
- 长按书签圆形图标弹出菜单（编辑 / 删除 / 取消主页显示）。
- 在网页中按 `Ctrl+D` 可将当前网页直接加入书签。
- 书签以圆形图标（64×64，`border-radius: 50%`）网格展示。

### 3.3 搜索（Omnibox）

- 输入 URL 回车 → 直接访问该网址。
- 输入非 URL 文本回车 → 用默认搜索引擎搜索（可在「设置 → 行为」中切换 Bing / Google / 百度 / DuckDuckGo）。
- 下方可拖拽分割线调整 Omnibox 宽度（200–720px）。

## 四、画布功能

### 4.1 画布面板（创建 / 切换 / 删除）

- **创建**：侧边栏底部 `+ 新建`，或快捷键 `Ctrl+N`。
- **切换**：点击侧边栏中的面板名称。
- **重命名 / 删除**：右键面板项或进入画布后通过 UnifiedToolbar 的设置按钮。
- 删除前面板可在「设置 → 行为」中开启「删除前确认」。

### 4.2 组件管理

- **添加组件**：UnifiedToolbar 上的 `+ 添加` 按钮，或画布主页的 `+ 添加组件`。
- **移动**：拖拽组件标题栏即可自由移动；「设置 → 行为」可开启「组件吸附边缘」。
- **缩放**：拖拽组件右下角调整尺寸。
- **删除**：组件右上角关闭按钮，或右键菜单中的「删除」。
- **图层**：右键菜单提供「移到最前 / 移到最后 / 上移 / 下移」。
- **锁定 / 最小化**：右键菜单切换。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Shift+Z`（仅画布作用域，组件移动/删除可撤销）。

### 4.3 收藏组件

- 在画布中右键组件 → 选择「收藏」即可加入收藏。
- 收藏组件在画布主页以预览卡片形式展示：
  - **预览模式**：渲染组件的静态快照（如 FocusTimer 显示当前模式、MusicPlayer 显示封面，但不跑计时器、不加载音频）。
  - **图标模式**：仅显示组件类型图标。
- 点击收藏卡片可跳转到对应面板的对应位置（`teleportTo`）。
- 按 `Ctrl+D` 可将当前选中组件加入收藏。

### 4.4 无限画布（平移 / 缩放）

| 操作 | 效果 |
|------|------|
| 鼠标滚轮 | 上下平移画布 |
| `Ctrl` + 滚轮 | 缩放画布（0.2× – 5×） |
| `Ctrl+=` | 放大 |
| `Ctrl+-` | 缩小 |
| `Ctrl+0` | 重置缩放为 1× |
| 中键拖拽 / 空格 + 拖拽 | 平移画布 |
| 右下角小地图 | 点击或拖拽快速跳转 |

## 五、AI 助手

### 5.1 唤起 AI 输入框

- **画布主页**：点击中央 pill 输入框展开对话区域。
- **全局快速输入**：单独按下**左 Alt** 键唤起浮动输入框（适合在浏览器或任意视图快速向 AI 提问）。
- **Omnibox 命令**：在地址栏输入 `ai:` 前缀可直接发起 AI 对话。

### 5.2 发送消息

- 在输入框输入文本后回车发送（`Shift+Enter` 换行）。
- AI 回复以消息气泡形式呈现；思考中时显示 typing dots 动画。
- 错误时显示错误条；可点击「重试」重新发送。

### 5.3 AI 命令

AI 可解析特定命令并执行：

- `/创建面板 <名称>`：新建画布面板并切换。
- 其他工具调用由服务器 pi 桥接处理（详见服务器文档）。

### 5.4 在线状态

画布主页 pill 输入框左侧的小圆点：

- 🟢 绿色：WS 已连接，AI 可用。
- 🔴 红色：WS 断开，发送消息会进入重连队列。

## 六、收藏管理

设置面板的「收藏管理」Tab 提供完整的收藏组件管理界面。

### 6.1 添加收藏

- 在画布中右键组件 → 选择「收藏」。
- 选中组件后按 `Ctrl+D`。
- 收藏成功后画布主页的「收藏组件」网格会立即更新。

### 6.2 排序

收藏管理列表顶部提供 4 种排序模式的 pill 按钮组：

| 模式 | 说明 |
|------|------|
| 手动 | 通过 HTML5 拖拽重排，仅在「全部分组」视图下可用 |
| 名称 | 按 `displayName` 字母序（中文按拼音） |
| 创建时间 | 按 `createdAt` 升序 |
| 最近使用 | 按 `lastUsedAt` 降序（无值时回退到 `createdAt`） |

### 6.3 分组

左侧 sidebar 显示分组列表：

- **全部分组** / **未分组**：内置视图。
- **新建分组**：点击底部 `+ 新建分组`，输入名称回车。
- **重命名**：双击分组名，或点击右侧 ✏️ 图标。
- **删除**：点击 🗑 图标；若组内有收藏，弹窗选择迁移目标（迁移到其他分组 / 不迁移变为未分组）。
- **拖拽收藏到分组**：将右侧收藏项拖到左侧分组上即可移动。
- **批量迁移**：点击收藏项右侧 📂 图标，在弹窗中选择目标分组。

### 6.4 搜索

- 顶部 pill 形搜索框，实时过滤（200ms 防抖）。
- 大小写不敏感，匹配 `displayName` / `groupName` / `widgetType`。

### 6.5 导出

- 点击右上角 ⬇ 图标，将当前收藏列表导出为 JSON 文件（文件名 `favorites-YYYY-MM-DD.json`）。

- 标记为「只读」的快捷键（`Ctrl+W` / `Ctrl+Tab` / `Ctrl+1..9` / `Ctrl+=/-/0` / `Ctrl+R`）因匹配逻辑特殊，不支持自定义。

## 八、设置

设置面板从右侧抽屉滑出，含 **8 个 Tab**（pill 形状，可横向滚动）：

1. 外观
2. 行为
3. 动效与无障碍
4. 收藏管理
5. 快捷键
6. 数据管理
7. 服务器
8. AI 配置

### 8.1 外观

- **主题预设**：18 套预设（亮色 10 套：Editorial / Linear / Airbnb / GitHub / Notion / Stripe / Vercel / Apple / Sakura / Sage；暗色 8 套：深空黑 / 午夜蓝 / 暗紫 / 深海绿 / 暖橙夜 / 玫瑰夜 / 极光 / 森林）。点击即应用。
- **背景**：可选纯色 / 渐变 / 图片。渐变含 14 套预设（晨曦 / 蜜桃 / 薄荷糖 / 天际 / 极光绿 / 日落 / 深海 / 星空 / 暮光 / 火山 / 冰川 / 薰衣草田 / 极夜 / 翡翠），支持自定义 CSS 渐变值。图片背景支持上传 JPG/PNG/WebP。
- **主页模板**：3 个模板（详见第九章）。
- **颜色**：强调色 / 表面颜色 / 文字颜色 / 表面透明度（0–100%）/ 表面模糊（0–20px）/ 字体大小（12–20px）。
- **主页定制**：分别为浏览器主页与画布主页上传背景图、设置 Logo URL、主题色；画布主页额外可上传中央圆形图标。

### 8.2 行为

- **默认搜索引擎**：Bing / Google / 百度 / DuckDuckGo。
- **默认布局模式**：自由拖拽 / 网格对齐。
- **内存休眠**：开启后非活跃面板自动休眠以释放内存；可设置等待时间（1/3/5/10/30 分钟）与内存阈值（1/1.5/2/4/8 GB）。
- **删除前确认**：开关。
- **组件吸附边缘**：开关。

### 8.3 动效与无障碍

- **减少动画**：开启后通过 `data-reduce-motion="true"` 属性禁用界面过渡和动画（适合对动效敏感或性能较差的设备）。
- **字体大小**：小（13px）/ 中（14px，默认）/ 大（16px），通过 `--font-size-base` CSS 变量应用。
- **高对比度模式**：开启后通过 `data-high-contrast="true"` 属性增强文字与背景对比度。
- **禁用毛玻璃效果**：将 `--glass-blur` 与 `--backdrop-blur` 置为 0，减少 GPU 占用。
- **恢复默认**：一键重置全部无障碍设置。
- 持久化在 `localStorage`，key 为 `ld_accessibility`。

### 8.4 收藏管理 Tab

详见第六章。

### 8.5 快捷键 Tab

详见第七章第 7.5 节。

### 8.6 数据管理

- **导出数据**：下载 JSON 备份文件（含版本校验与字段白名单），文件名 `living-dashboard-v2-backup-YYYY-MM-DD.json`。
- **导入数据**：从 JSON 文件恢复，导入前会提示先备份。导入后页面自动刷新。

### 8.7 服务器

- **设备 ID**：本机唯一标识（只读）。
- **API Base URL** / **WS URL**：通过项目根目录 `.env.local` 的 `VITE_API_BASE_URL` / `VITE_WS_URL` 配置（只读展示）。
- **服务器 Token**：与服务器 `SERVER_TOKEN` 一致，保存后需重新连接 WS 生效。

### 8.8 AI 配置

包含 3 个子区域：

- **API 配置**：模型选择（默认 `step-3.7-flash`）、API 可用性检测。
- **提示词配置**：系统提示词 / 用户偏好。
- **Skills 管理**：启停 AI 可用的工具技能。

## 九、主页模板

设置面板「外观 → 主页模板」提供 3 个内置模板，点击即切换。当前模板仅影响**画布主页**的展示。

### 9.1 极简（minimal）

- 仅显示：圆形图标 + pill 形 AI 输入框。
- 隐藏：收藏组件网格、快捷链接、最近访问面板。
- 适用：偏好极简界面、希望专注 AI 对话的用户。

### 9.2 标准（standard）

- 显示：圆形图标 + pill 形 AI 输入框 + 收藏组件网格。
- 适用：大多数用户的默认选择。

### 9.3 丰富（rich）

- 在标准模板基础上额外显示：
  - **快捷链接区**：取前 6 个网页标签作为快速入口。
  - **最近访问面板区**：排除当前面板，按 `order` 降序取前 4 个面板。
- 适用：希望主页信息密度更高的用户。

> Spec 中提到的 `custom` 自定义模板暂未实现，当前仅上述 3 个内置模板。

## 十、常见问题（FAQ）

**Q1：启动后看不到任何面板？**
A：首次启动数据库为空，点击侧边栏 `+ 新建` 创建第一个画布面板即可。

**Q2：按 Ctrl+W 把窗口关了？**
A：不会。主进程通过 `before-input-event` 拦截了 `Ctrl+W`，仅关闭当前网页标签，不会关闭窗口。

**Q3：Ctrl+R 刷新了整个窗口导致数据丢失？**
A：不会。`Ctrl+R` / `F5` 已被主进程拦截，仅刷新当前 webview，不影响其他标签或画布。

**Q4：AI 输入框显示红点（离线）怎么办？**
A：检查「设置 → 服务器」中的 Token 是否正确，以及服务器是否运行。WS 断开后会自动重连（指数退避，最长 30 秒）。

**Q5：嵌入网页到画布后，组件加载很慢？**
A：webview 并发池上限为 4，超出会排队等待。可关闭不用的标签释放位置。

**Q6：自定义快捷键后想恢复？**
A：在「设置 → 快捷键」中，单条点击 ↻ 图标恢复；批量点击顶部「恢复默认」按钮。

**Q7：减少动画后界面变得很生硬？**
A：在「设置 → 动效与无障碍」关闭「减少动画」开关即可恢复。

**Q8：导出的收藏列表 JSON 怎么用？**
A：JSON 是收藏列表的原始数据，可作为备份；目前桌面端未提供导入收藏的入口，需要时可通过服务器 API 写入。

**Q9：主题切换后某些组件颜色不对？**
A：部分自定义颜色组件（如 FocusTimer / MusicPlayer）使用 `colorScheme`，可在画布中右键组件 →「颜色方案」单独切换。

**Q10：能在多台电脑间同步数据吗？**
A：可以。配置同一台服务器与 Token 后，面板 / 组件 / 收藏 / 书签会通过 WS 实时同步；离线时通过 syncQueue 入队，恢复后批量回写。
