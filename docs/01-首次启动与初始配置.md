# 首次启动与初始配置

## 一、启动项目

### 1.1 安装依赖（仅首次）

打开终端，进入项目目录：

```bash
cd f:\allmylife\event
npm install
```

### 1.2 启动开发服务器

```bash
npm run dev
```

启动后终端会显示本地地址，通常是 `http://localhost:5173`，在浏览器中打开即可。

如需局域网访问（手机等设备），使用：

```bash
npm run dev -- --host
```

### 1.3 构建生产版本（可选）

```bash
npm run build
npm run preview
```

## 二、首次配置 AI 助手

AI 助手是整个项目的核心交互入口，首次使用必须完成以下配置。

### 2.1 添加 AI 助手组件

1. 点击顶部工具栏的 **「添加」** 按钮（+ 图标）
2. 在弹出的组件面板中，找到 **「AI 助手」** 分类
3. 点击 **「AI 助手」** 组件，它会被添加到画布上
4. 拖动组件调整位置，拖动右下角调整大小（建议拉大到 400x500 以上，方便对话）

### 2.2 接受隐私声明

首次打开 AI 助手组件，会看到隐私提示页面：

- 阅读隐私说明（核心要点：对话发送到远程 AI、个人数据默认不发送、API Key 加密存储等）
- 点击 **「我已了解，继续」** 按钮

### 2.3 配置 API Key

> **重要**：API Key 配置入口在 AI 助手组件的 **上下文面板** 中，不在全局设置面板。

1. 点击 AI 助手头部的 **☰** 按钮，打开上下文面板
2. 在上下文面板中找到 API Key 输入区域
3. 输入你的 **API Key**
4. 选择存储模式：
   - **仅本次会话**（session）：关闭浏览器后失效，下次需重新输入
   - **加密存储**（persistent）：使用密码加密后保存在本地，下次输入密码即可恢复
5. 如果选择加密存储，设置一个加密密码并记住它

> **默认配置**：
> - API 端点：`https://api.st0722.top/v1/chat/completions`
> - 默认模型：`deepseek-v4-flash`
> - 备用模型：`deepseek-v4`
>
> 如果你使用其他 API 服务，需要修改代码中 `src/ai/llmBackend.ts` 的 `DEFAULT_LLM_CONFIG`。

### 2.4 验证 AI 是否可用

1. 在 AI 助手的输入框中输入一条测试消息，如：`你好，请介绍一下你自己`
2. 按 **Enter** 或点击 **「发送」** 按钮
3. 观察：
   - 如果 AI 助手头部显示 **「离线」** 红色标签 → API Key 或端点配置有误，检查配置
   - 如果输入框上方出现加载动画 → 正在请求，等待回复
   - 如果收到 AI 的回复 → 配置成功

### 2.5 选择模型

在 AI 助手头部右侧有一个模型下拉框。可选模型取决于你的 API 服务返回的列表，代码中预设的可选模型包括：

- `deepseek-v4-flash`（默认，速度快）
- `gpt-5.5`
- `gpt-5.4`
- `gemini-3.5-flash`
- `claude-sonnet-4.6`

> **注意**：`deepseek-v4` 是代码中配置的备用模型（fallback），当主模型请求失败时自动切换，不在下拉框中手动选择。实际可用模型以 API 服务 `/v1/models` 接口返回为准。

## 三、理解画布与面板系统

### 3.1 画布操作

| 操作 | 方法 |
|------|------|
| 拖动画布 | 点击工具栏 **「拖动」** 按钮（或按 H 键），然后拖动画布 |
| 选择组件 | 点击工具栏 **「选择」** 按钮（或按 V 键），然后点击组件 |
| 缩放 | 使用工具栏的 +/- 按钮，或鼠标滚轮 |
| 重置缩放 | 点击工具栏中间的百分比数字 |

### 3.2 面板（Panel）系统

面板是画布的独立空间，不同面板之间互不干扰。

- 点击工具栏 **「面板」** 按钮查看面板列表
- 点击 **「新建面板」** 创建新面板
- 点击面板名称切换到该面板
- 每个面板有独立的组件布局和画布坐标
- **重要**：任务和日程是按面板隔离的，不同面板有各自独立的任务列表和日程列表

**建议**：为不同场景创建不同面板，如：
- 「学习」面板：放学习相关组件和任务
- 「生活」面板：放生活管理组件和任务
- 「休闲」面板：放音乐、数独等

### 3.3 坐标传送

画布是无限大的，你可以把组件放在任意位置。

- 点击工具栏 **「坐标传送」** 按钮（定位图标）
- 输入 X、Y 坐标，点击 **「传送」** 跳转到该位置
- 点击 **「回到原点」** 回到坐标 (0, 0)
- 可以保存 **书签**：输入书签名称，点击 **「保存」**，以后点击书签即可快速跳转

**建议**：
- 学习区域放在坐标 (0, 0) 附近
- 生活区域放在坐标 (2000, 0) 附近
- 休闲区域放在坐标 (0, 2000) 附近
- 为每个区域保存书签，方便快速切换

### 3.4 组件操作

| 操作 | 方法 |
|------|------|
| 添加组件 | 工具栏 → 添加 → 选择组件类型 |
| 移动组件 | 选择模式下拖动组件标题栏 |
| 调整大小 | 拖动组件右下角 |
| 删除组件 | 点击组件右上角的 × 按钮 |
| 搜索组件 | 工具栏 → 添加 → 在搜索框中输入关键词 |

## 四、组件分类总览

以下分类基于代码中的 `widgetDefinitions.ts`：

| 分类 | 组件 | 用途 |
|------|------|------|
| **基础组件** (basic) | 富文本、时钟、Markdown编辑器、贴纸、便签、倒计时卡片 | 基础记录与展示 |
| **媒体与阅读** (media) | PDF查看器、音乐播放器、名言卡片 | 媒体消费与阅读 |
| **时间与任务** (work) | 专注计时器、任务列表、统计面板、日程列表 | 任务管理与时间规划 |
| **生活与健康** (life) | 习惯追踪器、心情追踪器、呼吸练习、日记、随身记、储蓄目标 | 生活记录与健康管理 |
| **统计面板** (stats) | 统计面板 | 数据可视化 |
| **AI 助手** (ai) | AI 助手 | AI 对话与工具调用 |
| **学习工具** (study) | LaTeX出题器、计算器、单词记忆、数独、错题本 | 学习与练习 |

> **注意**：以上分类基于代码 `widgetDefinitions.ts` 中的 `category` 字段。工具栏添加面板中的分类标签可能略有不同（如显示为"基础组件""时间与任务""生活与健康""媒体与阅读""统计面板""AI 助手""学习工具"）。

## 五、首次使用建议布局

完成以上配置后，建议按以下步骤搭建初始布局：

### 5.1 创建面板

1. 新建面板，命名为 **「学习」**
2. 新建面板，命名为 **「生活」**
3. 新建面板，命名为 **「休闲」**

### 5.2 在「学习」面板中添加组件

1. 切换到「学习」面板
2. 添加 **AI 助手**（放在左侧，拉大）
3. 添加 **任务列表**（放在右上）
4. 添加 **LaTeX 出题器**（放在右中）
5. 添加 **错题本**（放在右下）
6. 添加 **专注计时器**（放在左下角，小尺寸）

### 5.3 在「生活」面板中添加组件

1. 切换到「生活」面板
2. 添加 **AI 助手**（放在左侧）
3. 添加 **日程列表**（放在右上）
4. 添加 **任务列表**（放在右中）
5. 添加 **日记**（放在右下）
6. 添加 **习惯追踪器**（放在左下）

### 5.4 在「休闲」面板中添加组件

1. 切换到「休闲」面板
2. 添加 **音乐播放器**（放在左上）
3. 添加 **数独**（放在右上）
4. 添加 **呼吸练习**（放在左下）

### 5.5 保存书签

在每个面板中，点击坐标传送 → 保存书签：
- 学习面板：书签名「学习区」
- 生活面板：书签名「生活区」
- 休闲面板：书签名「休闲区」

## 六、数据存储说明

- 所有数据存储在浏览器的 **IndexedDB** 中，本地持久化
- 关闭浏览器后数据不会丢失
- 清除浏览器数据会删除所有数据（可通过设置中的导出功能备份）
- 数据备份：点击工具栏 **「设置」** → **「数据管理」** → **「导出数据」**
- 数据恢复：点击工具栏 **「设置」** → **「数据管理」** → **「导入数据」**
