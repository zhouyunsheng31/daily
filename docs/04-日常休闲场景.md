# 日常休闲场景 — 完整使用链路

## 场景概述

学习之余需要放松，本项目提供了音乐播放、数独游戏、呼吸练习等休闲组件。

---

## 一、音乐播放

### 1.1 切换到休闲面板

1. 点击工具栏 **「面板」** → 选择 **「休闲」** 面板
2. 或点击坐标传送 → 点击 **「休闲区」** 书签

### 1.2 添加音乐文件

在 **音乐播放器** 组件中：

1. 点击 **「选择文件」** 按钮
2. 选择本地音乐文件（支持所有浏览器支持的音频格式）
3. 文件会被加载到播放器中
4. 可以选择多个文件形成播放列表

### 1.3 播放控制

| 操作 | 方法 |
|------|------|
| 播放/暂停 | 点击播放按钮 |
| 上一首/下一首 | 点击切换按钮 |
| 调整音量 | 拖动音量滑块 |
| 进度控制 | 拖动进度条 |

### 1.4 让 AI 控制音乐

```
帮我播放音乐
```

AI 会调用音乐工具控制播放器。

### 1.5 边听音乐边学习

1. 在休闲面板启动音乐播放器
2. 切换到学习面板继续学习
3. 音乐会在后台继续播放（前提是音乐播放器组件没有被卸载）

> **注意**：如果切换面板导致音乐播放器组件被卸载（比如该面板没有任何组件引用），音乐会停止。建议在休闲面板保留音乐播放器组件。

## 二、数独游戏

### 2.1 开始新游戏

在 **数独** 组件中：

1. 选择难度：
   - `easy`（简单）
   - `medium`（中等）
   - `hard`（困难）
2. 点击 **「新游戏」** 按钮
3. 系统自动生成数独题目

### 2.2 游戏操作

| 操作 | 方法 |
|------|------|
| 填入数字 | 点击空格，选择1-9的数字 |
| 笔记模式 | 开启笔记模式，在格子里标记候选数字 |
| 撤销 | 点击撤销按钮 |
| 清除 | 点击 ✕ 按钮清除当前格子的数字 |

> **注意**：数独没有手动"检查"按钮。当所有格子填满后，系统会自动检查是否正确。

### 2.3 游戏状态

- 游戏进度自动保存
- 关闭组件后重新打开可以继续
- 完成后显示恭喜消息

### 2.4 让 AI 辅助数独

```
我卡在数独上了，给我一点提示，但不要直接告诉我答案。
```

AI 可以查看当前数独状态（需授权），给出提示。

## 三、呼吸练习

### 3.1 选择呼吸模式

在 **呼吸练习** 组件中，选择模式：

- **4-7-8**：吸气4秒、屏息7秒、呼气8秒（放松助眠）
- **Box**：吸气4秒、屏息4秒、呼气4秒、屏息4秒（均衡放松）
- **Relaxing**：吸气4秒、呼气6秒（简单放松）

### 3.2 开始练习

1. 选择模式
2. 点击开始
3. 跟随动画节奏呼吸
4. 练习时长自定

### 3.3 使用场景

- 学习累了需要休息时
- 考试前紧张需要放松时
- 睡前需要平静时

---

## 四、名言卡片

### 4.1 查看名言

**名言卡片** 组件会显示一条名言，可以：
- 点击刷新获取新名言
- 自定义名言内容

### 4.2 使用场景

- 放在画布角落作为激励
- 学习疲惫时看看名言换换心情

---

## 五、PDF 阅读

### 5.1 打开 PDF

在 **PDF 查看器** 组件中：

1. 点击 **「选择文件」** 按钮
2. 选择本地 PDF 文件
3. 文件会在组件中渲染显示

### 5.2 阅读操作

- 翻页：点击上下页按钮
- 阅读进度自动保存
- 下次打开会从上次阅读的位置继续

### 5.3 使用场景

- 阅读学习资料
- 查看考试真题 PDF
- 阅读电子书

---

## 六、画笔与便签

### 6.1 使用画笔

1. 点击工具栏 **「画笔」** 按钮（或按 P 键）
2. 选择画笔类型：
   - 画笔（自由绘制，快捷键 P）
   - 直线（快捷键 L）
   - 箭头（快捷键 A）
   - 矩形（快捷键 R）
   - 椭圆（快捷键 O）
   - 文本（快捷键 T）
3. 在画布上绘制

### 6.2 使用便签（NoteBlock）

1. 添加 **便签** 组件（在工具栏添加面板的「基础组件」分类中）
2. 输入内容
3. 可以选择颜色
4. 放在画布任意位置作为提醒

### 6.3 使用贴纸（Sticker）

1. 添加 **贴纸** 组件（在工具栏添加面板的「基础组件」分类中）
2. 输入 emoji 和标签文字
3. 放在画布上作为装饰或标记

### 6.4 使用场景

- 在画布上画思维导图
- 用便签做临时笔记
- 用箭头连接相关组件

---

## 七、休闲与学习的平衡

### 7.1 番茄工作法

1. 在学习面板打开专注计时器
2. 学习25分钟
3. 休息5分钟（切换到休闲面板玩一局数独或听首歌）
4. 重复

### 7.2 快速切换

使用书签在学习和休闲之间快速切换：
- 学习累了 → 坐标传送 → 「休闲区」
- 休息够了 → 坐标传送 → 「学习区」

### 7.3 让 AI 提醒休息

```
我学了1个小时了，提醒我休息一下。
```

AI 可以帮你设置专注计时，时间到了会提醒你。
