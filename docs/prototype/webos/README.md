1. [方向 A：Quiet Intelligence / 安静智能](direction-a-quiet.html)
2. [方向 B：Living Space / 流体空间](direction-b-living.html)

方向 A 已被选为首版默认且唯一主题，并已改为横向展示六台设备的 P0 产品全景：

1. 游客 AI 首页与余额；
2. 系统桌面和四个默认系统应用；
3. 邮箱绑定、模型选择和四档思考强度；
4. 余额、充值包和“支付服务待接入”状态；
5. AI 生成、费用预估和 `app.storage.private` 授权；
6. HTML App 全屏运行、不可变版本和回滚入口。

方向 A 本轮按用户要求为静态展示，不要求点击交互。方向 B/C 仍保留原有四状态可点击方向原型，仅作为后续可选主题参考。所有原型均不调用真实 AI、邮箱验证码或支付能力；首版明确暂缓 ASR/TTS。

## 已选方向与后续定位

| 方向 | 当前定位 | 首版处理 |
|---|---|---|
| A 安静智能 | 编辑式 AI 首页、传统图标桌面、克制系统 Gate | **已选定；首版默认且唯一主题** |

## 方向 A 的 P0 评审重点

- 首次打开自动获得游客身份和免费余额，不出现登录 Gate；
- 邮箱验证码入口表达为“绑定并同步”，不阻止游客使用；
- 模型和思考强度分成两个独立区域；
- 桌面至少展示 Daily AI、系统桌面、文件和设置；
- 支付页面是 P0，但真实 Provider 未接入时明确禁用，不伪造成功；
- AI 生成前展示模型、思考强度、费用预估、余额和唯一权限；
- App 默认全屏运行，修改创建不可变新版本并支持回滚；
- 页面中不出现麦克风、监听波形或任何 ASR/TTS 入口。

## 原型验证状态

- 方向 A：本轮是静态产品全景，按用户要求不以点击闭环作为验收；应检查六个 P0 状态是否完整、无语音入口、无登录 Gate、无虚假支付成功。
- 方向 B/C：此前的交互与自动化结果保留，仅用于未来主题参考，不再决定首版产品范围。
- 三个文件均为自包含 HTML，不加载外部字体、图片、脚本或真实 API。

## 首版视觉落点

- **A 的整体信息密度、文字交互和传统桌面认知**作为生产 Shell 基线；
- **C 的系统权限 Gate、版本标识、Diff 与审计思想**用于生成、安装和修改详情，不常驻普通用户首屏；
- B 的环境动效与 B/C 整体主题均延后，不进入首版；B 中语音表达不纳入已确认的首版主题。
