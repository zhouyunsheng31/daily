## 详细演示步骤

### 步骤 1：打开 Daily → 三层画布 + 背景层

**操作**：
1. 浏览器打开 `https://shadowshub.xyz/daily/`
2. 登录后进入主画布

**预期效果**：
- 看到三层画布结构：
  - **背景层**（最底，z:0）：固定视口，不随画布平移/缩放
  - **组件层**（中间，z:10）：参与画布平移/缩放
  - **弹出层**（最上，z:1000）：临时弹出
- 背景层显示默认颜色/渐变
- 右上角显示"shadowshubs"入口按钮 + "设置"按钮
- 左上角显示面板切换器
- 右下角显示添加组件 FAB 按钮

**展示要点**：
- 强调"三层画布模型"是 Daily 的核心架构
- 背景层始终存在，不会因缩放消失

---

### 步骤 2：浮球形态 → 切换底部任务栏

**操作**：
1. 观察右下角浮球（FloatingOrb）形态
2. 点击浮球上的切换按钮（ArrowLeftRight 图标）
3. 切换到底部任务栏（BottomTaskbar）形态

**预期效果**：
- 浮球形态：右下角圆形浮球，点击展开对话输入框
- 切换后：底部出现椭圆形输入栏 + 上方对话历史气泡区
- 上方气泡区显示微信风格聊天气泡（用户靠右紫色，AI 靠左灰色）

**展示要点**：
- 两种 AI 对话形态可切换，适配不同使用场景
- 底部任务栏适合长时间对话，浮球适合快速指令

---

### 步骤 3：与 AI 对话 → 生成 HTML 组件放画布

**操作**：
1. 在底部任务栏输入框输入指令，例如：
   ```
   帮我在画布上放一个带动画的欢迎卡片，显示"Daily Demo"
   ```
2. 按 Enter 发送
3. 等待 AI 流式响应（看到 ThinkingBar → 工具调用 → 生成组件）

**预期效果**：
- AI 通过 WebSocket 流式响应
- 状态栏依次显示：思考中 → 工具调用中 → 完成
- AI 调用 `create_widget` 工具，在画布上生成一个 freeHtml 组件
- 组件显示在画布上，可拖动、可调整大小

**展示要点**：
- AI Agent 是核心能力，能理解自然语言指令
- AI 直接操控画布，生成可交互的 HTML 组件
- WebSocket 流式响应，实时看到 AI 思考过程

---

### 步骤 4：滚轮缩放 → 三档吸附

**操作**：
1. 鼠标放在画布空白处
2. 向下滚动滚轮 → 缩小到 mini 档
3. 继续向下滚动 → 缩小到 icon 档
4. 向上滚动滚轮 → 依次恢复到 mini → normal 档

**预期效果**：
- **normal 档**（zoom > 1.0）：完整显示组件
- **mini 档**（0.5 < zoom ≤ 1.0）：组件缩放为 0.5，视口外虚拟化
- **icon 档**（zoom ≤ 0.5）：组件卸载 iframe，渲染圆形首字母占位图标
- 每次吸附时画面中央显示档位指示器（1 秒消失）
- 右上角"相册"按钮可调整档位触发值

**展示要点**：
- 相册三档缩放是 Daily 的特色交互
- icon 档卸载 iframe 省性能，适合大量组件概览
- 普通滚轮三档吸附，Ctrl/⌘+滚轮自由缩放

---

### 步骤 5：注册/登录 → 创建个人面板

**操作**：
1. 点击右上角"设置" → 退出登录（如已登录）
2. 在登录页点击"注册"切换到注册模式
3. 输入用户名 + 密码注册
4. 登录后点击左上角面板切换器 → "新建个人面板"
5. 创建 2-3 个个人面板，切换查看

**预期效果**：
- 注册/登录流程完整
- 创建面板后面板切换器中显示"个人面板"分组
- 不同面板独立存储组件，切换时画布内容更新

**展示要点**：
- 多用户系统支持注册/登录/角色
- 个人面板可多建，独立隔离

---

### 步骤 6：创建社区面板（admin）

**操作**：
1. 用 admin 账号登录
2. 点击面板切换器 → "新建社区面板"（仅 admin 可见）
3. 创建一个社区面板

**预期效果**：
- 面板切换器中显示"社区面板"分组（在个人面板之上）
- 社区面板与个人面板分组显示

**展示要点**：
- 社区面板需要 admin 权限创建
- 个人面板 vs 社区面板分组显示

---

### 步骤 7：AI 控制背景 → 加特效（下雨）

**操作**：
1. 与 AI 对话，输入指令：
   ```
   把背景改成下雨的动画特效
   ```
2. 等待 AI 调用 `set_background` 工具

**预期效果**：
- 背景层切换为下雨动画（CSS/Canvas 粒子）
- 背景层固定视口，不随画布平移/缩放
- 组件层仍在背景层之上正常显示

**展示要点**：
- AI 可控制背景层（图片/颜色/动画）
- 背景层与组件层独立，互不影响

---

### 步骤 8：弹出层触发 → 登录窗口

**操作**：
1. 触发弹出层（例如：未登录状态访问受保护资源，或 AI 调用 `show_popup` 工具）
2. 观察弹出层从最上层 z:1000 浮现

**预期效果**：
- 弹出层覆盖整个视口（z:1000，最上层）
- 显示登录窗口或其他弹层内容
- 关闭后回到画布

**展示要点**：
- 弹出层是三层画布模型的最上层
- 支持 AI 触发或系统触发

---

### 步骤 9：社区发现 → 官方社区列表

**操作**：
1. 点击右上角"设置"按钮
2. 在设置页左侧切换到"社区发现"标签

**预期效果**：
- 显示"官方社区列表"section
- shadowshubs 排在第一位，带"内置"标签 + 突出渐变背景
- 下方显示其他官方社区（Daily 官方社区、游戏开发者社区、设计师社区）
- shadowshubs 右侧按钮是"进入"（蓝色），其他是"添加"
- 下方有"手动添加社区"和"已加入的社区"section

**展示要点**：
- 联邦式社区模型：每个 Daily 部署是独立社区实例
- shadowshubs 是内置官方社区，无需添加可直接进入

---

### 步骤 10：shadowshubs 内置社区面板

**操作**：
1. 在社区发现页点击 shadowshubs 的"进入"按钮
2. 或在任意页面点击右上角"shadowshubs"入口按钮

**预期效果**：
- 跳转到 `/shadowshubs` 路由
- 显示 shadowshubs 面板视图：
  - 顶部导航栏（返回 + 社区发现按钮）
  - 面板头部：shadowshubs 图标 + 名称 + "官方内置"标签 + 描述
  - 黄色提示框：能力整合框架阶段说明
  - 4 个能力 widget 网格：
    - **游玩大厅**（PlayLobbyWidget）：游戏手柄图标，蓝色渐变
    - **Skill 市场**（SkillsGalleryWidget）：包裹图标，紫色渐变
    - **素材市场**（AssetsMarketWidget）：图片图标，黄绿渐变
    - **联机游戏**（RealtimeGameWidget）：WiFi 图标，红紫渐变
  - 每个 widget 有"开发中"标签 + 禁用的"进入"按钮

**展示要点**：
- shadowshubs 做成 Daily 的内置官方社区面板（不是独立部署）
- 4 个能力为框架占位，后续逐步拆解为 Daily widget
- 体现"Daily 是可扩展平台"的定位

## 注意事项

### 演示前准备
1. **确保后端服务正常**：`docker compose -f docker-compose.prod.yml up -d`
2. **确认环境变量**：`.env.prod` 中 JWT_SECRET / WEB_ACCESS_PASSWORD / CORS_ORIGIN 已正确配置
3. **准备测试账号**：至少 1 个 admin 账号 + 1 个普通用户账号
4. **网络稳定**：确保 WebSocket 连接稳定（AI 对话依赖 WS）
5. **浏览器**：使用 Chrome/Edge 最新版，确保 CSS zoom / backdrop-filter 支持

### 常见问题处理
- **AI 不响应**：检查 PI_API_KEY 是否配置，WS 是否连接（看 OfflineBanner）
- **背景层不显示**：确认 BackgroundLayer 组件在 Workspace 中渲染
- **shadowshubs 入口不可见**：确认已登录（AuthGuard 保护），右上角应有蓝色"shadowshubs"按钮
- **缩放无反应**：确保鼠标在画布空白处（非组件内/工具栏内）

### 演示话术建议
- 强调"画布 + AI Agent"的核心定位
- 突出"三层画布模型"的架构创新
- 展示"AI 直接操控画布"的交互方式
- 说明"联邦式社区"的可部署性
- 点明"shadowshubs 整合"展示平台扩展性
